# 12. Disciplina epistemológica

H4 conserva cuatro niveles que no deben confundirse:

1. **evidencia observada/documentada**;
2. **explicación contemporánea** de óptica, adhesión, humedad o caracterización;
3. **inferencia histórica** sobre decisión, control o práctica;
4. **límite / explicación alternativa**.

Reglas preservadas:

- apariencia observada ≠ intención demostrada;
- medición actual ≠ teoría histórica atribuible;
- receta escrita ≠ práctica universal;
- identificación de material ≠ explicación completa de significado.

**Resultado:** CUMPLE.
