## B. Instrucción de producción específica (ejecutar literalmente con los datos canónicos de la H)

**Diseña y genera una ilustración conceptual original** a partir del movimiento intelectual FEHE de la unidad, no una representación literal del ejemplo H8/H9. Antes de crear, formular internamente una tesis visual en una frase: «La imagen hace visible que [operación intelectual] requiere [decisión/evidencia] bajo [incertidumbre]». Escoger escala y metáfora visual específicas: artistas, materiales, procesos y agencia humana cuando correspondan. Puede usar una escena central y detalles secundarios; debe existir una jerarquía clara y espacio para texto Moodle si se necesita.

Preferir densidad significativa sobre collage decorativo. Cada elemento de escena debe responder a una función intelectual y no usar una iconografía técnica universal sin relación con la H. Evitar texto pequeño incrustado si puede fallar la precisión; revisar ortografía de rótulos en caso de generarlos. Variar composición, iluminación y escala respecto de piezas anteriores para impedir monotonía.

**Integridad:** no usar imagen IA para sustituir fotografías de obra, micrografías, mapas analíticos, archivos históricos ni instrumentos reales. No inventar ensayos, fechas, fórmulas, resultados o autoría. Si se alude a una obra real, indicar que la escena es conceptual y no reconstrucción literal, salvo respaldo comprobado. La descripción y alt text se producen en el módulo PM1-03 tras revisar el resultado.
