# 0. Tesis de diseño OVAt-H3

H3 debe enseñar que un sistema material funciona por **relaciones de compatibilidad entre componentes**, no por la suma aislada de sus propiedades.

Pregunta rectora:

> **¿Qué hace que materiales diferentes puedan trabajar juntos y permanecer como un sistema, y qué evidencia permite reconstruir las decisiones que hicieron posible esa compatibilidad?**

Cadena operativa H3:

`reconocer componentes → identificar funciones → localizar interfaz crítica → relacionar propiedades + ambiente → observar evidencia de compatibilidad/falla → inferir decisión técnica → declarar límite → transferir criterio`

Movimiento longitudinal visible:

`H2 transformar → H3 combinar → H4 controlar superficies e interfaces`

# 2. Parámetros globales

## 2.1 Movimiento cognitivo

H3 aumenta complejidad al pasar de una cadena causal centrada en un material a una **red relacional de componentes**.

El estudiante debe poder distinguir:

- componente;
- función;
- interfaz;
- ambiente;
- evidencia de comportamiento;
- compatibilidad o incompatibilidad;
- inferencia;
- límite.

## 2.2 Producto reusable

**Mapa de Sistema Material H3 (MSM-H3)**.

Campos mínimos:

1. componentes principales;
2. función de cada componente;
3. interfaz o relación crítica;
4. propiedad relevante;
5. ambiente/condición de uso;
6. evidencia de compatibilidad o falla;
7. inferencia sobre decisión técnica;
8. límite o alternativa.

Regla D-028:

> **MSM-H3 debe caber en una sola vista o equivalente breve y no convertirse en ficha extensa.**

Ruta de reuso:

`F4 actividad central → F5 transferencia breve → F6 cierre → recuperación futura H4 → FD2`

H3 no exige todavía revisión formal del Caso Ancla A.

## 2.3 Caso rector

La producción debe usar un **caso situado de mortero/revestimiento romano como sistema**, seleccionado por evidencia y procedencia, no por celebridad.

Debe permitir observar al menos:

- soporte o sustrato;
- ligante;
- agregado/adición;
- interfaz o relación entre componentes;
- ambiente/uso;
- evidencia de desempeño o falla.

No usar “concreto romano” como receta universal.

## 2.4 Contraste

**Pintura mural romana o mosaico/pavimento** como transferencia breve.

El contraste debe probar si el criterio de compatibilidad viaja hacia un sistema con otra función material/visual. No constituye segunda actividad completa.

## 2.5 Profundidad científica

Entrar:

- compatibilidad;
- sistema material;
- matriz/agregado;
- ligante;
- interfaz;
- cohesión/adhesión;
- porosidad;
- humedad cualitativa;
- movimiento diferencial;
- reactividad puzolánica conceptual;
- falla/deterioro como evidencia.

Reservar:

- mecánica formal de interfaces;
- módulo elástico cuantitativo;
- termodinámica de superficies;
- adhesión molecular desarrollada;
- difusión formal;
- caracterización instrumental sistemática.

## 2.6 Andamiaje

**MEDIO.**

Respecto a H2:

- se mantienen categorías claras y cadena estable;
- se reduce modelado paso a paso;
- el estudiante identifica relaciones entre componentes con mayor autonomía;
- se evita retirar simultáneamente todos los apoyos.

## 2.7 Carga objetivo

Distribución orientativa:

# 3. F1 · Apertura / Bienvenida

## Función

Mover al estudiante desde “¿qué le ocurrió a este material?” hacia “¿qué ocurre cuando materiales distintos deben funcionar juntos?”.

## Apertura candidata

Presentar un sistema sencillo de tres componentes y preguntar:

> **Si cada material funciona bien por separado, ¿qué podría hacer que fallen al combinarse?**

La respuesta inicial puede identificar una relación crítica entre componentes o ambiente.

No es entrega calificada.

## Evidencia observable

Micro-predicción:

- qué componente/interfaz considera más crítica;
- qué evidencia buscaría para evaluar compatibilidad.

Se recupera en F6.

---

# 4. F2 · Marco común FEHE H3

## Función

Construir el lenguaje compartido de **sistema, componente, función, interfaz, compatibilidad, ambiente y falla**.

## Secuencia narrativa

### Movimiento A · De material a sistema

Recuperar H2 y mostrar que propiedades adecuadas por separado no garantizan desempeño conjunto.

### Movimiento B · Compatibilidad no significa igualdad

Mostrar que diferencias controladas de porosidad, rigidez, absorción o función pueden ser necesarias.

### Movimiento C · Interfaz

Introducir interfaz como zona de relación, no como capítulo técnico avanzado.

### Movimiento D · Ambiente

Incluir humedad, temperatura, sales y uso como condiciones que afectan el sistema.

### Movimiento E · Entonces / Ahora

**ENTONCES:** experiencia de oficio, proporciones prácticas, preparación de superficies, observación de fraguado/falla, adaptación local.

**AHORA:** mineralogía, porosidad, microestructura, análisis petrográfico, comportamiento higrotérmico cualitativo.

### Movimiento F · Compatibilidad patrimonial

`material más fuerte ≠ reparación más compatible`

## Evidencia observable

Dos pausas:

1. identificar una interfaz crítica;
2. distinguir evidencia de compatibilidad de inferencia sobre conocimiento técnico.

# 5. F3 · Profundización / Lectura

## Función

Profundizar por qué un sistema material puede conservar memoria de cómo fueron combinados sus componentes.

Eje sugerido:

> **“Cuando los materiales deben convivir: compatibilidad, interfaz y ambiente.”**

La lectura debe:

- evitar historia enciclopédica;
- explicar variedad regional/funcional de morteros;
- diferenciar ligante, agregado y adiciones;
- mostrar porosidad y humedad como propiedades de sistema;
- usar falla/deterioro con cautela como evidencia retrospectiva;
- introducir la dimensión patrimonial de materiales de reparación.

Pregunta puente:

> **¿Qué relación entre dos componentes parece decisiva para el comportamiento del sistema y qué evidencia permitiría sostenerlo?**

# 6. F4 · Actividad central

## Función

Construir un **MSM-H3** a partir de evidencia documental y material de un caso situado.

## Tarea

El estudiante debe:

1. identificar componentes;
2. asignar función material a cada uno;
3. señalar una interfaz o relación crítica;
4. seleccionar una propiedad pertinente;
5. incorporar una condición ambiental/uso;
6. conectar una evidencia con compatibilidad o falla;
7. formular una inferencia sobre decisión técnica;
8. declarar un límite o explicación alternativa.

## Producto

**MSM-H3 reusable, breve y formativo.**

No crear entrega adicional paralela.

## Criterios de calidad

Una respuesta fuerte:

- no trata el sistema como lista de ingredientes;
- conecta propiedades con relaciones entre componentes;
- distingue cohesión y adhesión cuando sea pertinente;
- evita atribuir teoría moderna a productores históricos;
- reconoce que supervivencia actual incluye historia ambiental/posterior;
- declara incertidumbre.

# 7. F5 · Transferencia / reuso

## Función

Probar si el criterio de compatibilidad puede viajar a otro sistema.

Contraste candidato:

- pintura mural romana, o
- mosaico/pavimento.

El estudiante reutiliza el MSM-H3 y modifica sólo lo necesario para responder:

> **¿Qué cambia cuando la función principal del sistema pasa de construir/estabilizar a revestir, representar o producir una superficie visual?**

# 8. F6 · Cierre longitudinal

## Función

Recuperar la micro-predicción inicial, sintetizar el salto de material a sistema y proyectar H4.

Debe hacer visible:

`material transformado → sistema combinado → superficie/interfaz controlada`

Síntesis conceptual:

> **un sistema material no se explica sólo por qué contiene, sino por cómo sus componentes se relacionan entre sí y con su ambiente.**

Puente H4:

> **¿Qué ocurre cuando esas interfaces y superficies dejan de ser sólo condiciones de compatibilidad y pasan a controlarse deliberadamente para producir color, luz, protección o efecto?**

No abre FD2.
