## 3. Decisiones rectoras vigentes

- GitHub `main` = fuente canónica.
- ChatGPT Project Ars Materia 101 = centro operativo.
- FEHE = instrumento histórico-epistemológico y especificación de diseño, no formulario.
- Cuatro lentes convergentes: histórico-cultural, material-científica, epistemológica, patrimonial-contemporánea.
- Clase y PROEMA se integran sin confundirse.
- Una función pedagógica requiere evidencia adecuada, no una tarea nueva.
- El patrón transfiere funciones, no superficies, formatos ni contenidos previos.
- REC: necesidad pedagógica → estrategia → evidencia → herramienta mínima.
- QA situado, auditoría inversa y Gate siguen siendo obligatorios para cada H.
- **Simetría OVAt = mismos componentes funcionales reconocibles; evolución longitudinal = mayor complejidad, autonomía e integración.**
- **Espiral de Casos = complejidad creciente + andamiaje decreciente + reuso longitudinal.**
- FD1-FD5 pertenecen a Clase; Portafolio de Casos no sustituye PROEMA.
- El estudiante conserva selección autónoma de su Caso Ancla.
- **Hallazgo H3:** la simetría funcional necesita una gramática editorial reconocible, sin convertirse en plantilla rígida de contenido.
