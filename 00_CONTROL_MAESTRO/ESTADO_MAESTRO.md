## 4. Decisiones vigentes

1. FEHE es instrumento de investigación histórico-epistemológica y especificación de diseño, no formulario.
2. Cuatro lentes: histórico-cultural, material-científica, epistemológica, patrimonial-contemporánea.
3. Clase e Investigación se integran, pero no se confunden.
4. Foros FD1-FD5 pertenecen a Clase.
5. PROEMA tiene cinco fases de aproximadamente tres semanas con productos tangibles acumulativos.
6. Ensayos PROEMA son individuales.
7. La tríada articula coherencia y sinergia sin sustituir autoría individual.
8. La propuesta grupal fija el prototipo estructural común OVAt.
9. Cada tríada produce el OVAt de una H asignada.
10. Bloque 6 incorpora epistemología, metacognición, referencias, progreso y continuidad.
11. Carga cognitiva: arquitectura estable + productos reutilizables + complejidad creciente + andamiaje decreciente.
12. GitHub es la fuente canónica; el Project es el espacio operativo.
13. La estructura completa del Framework se conserva en raíz y se activa según necesidad.
14. La trazabilidad de procesos, decisiones y metodologías tiene el mismo rango operativo que la producción educativa.
15. Una verdad viva por función; Git conserva genealogía y estados superados.
