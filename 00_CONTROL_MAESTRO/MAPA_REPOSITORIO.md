# MAPA DEL REPOSITORIO

```text
ars-materia-101/
├── 00_CONTROL_MAESTRO/
├── 01_FUNDAMENTOS/
├── 02_DOCUMENTO_RECTOR/
├── 03_FEHE_H1-H10/
│   ├── H1/
│   ├── H2/
│   ├── ...
│   └── H10/
├── 04_ALINEACION_Y_EVALUACION/
├── 05_PROEMA/
├── 06_OVAT_Y_MOODLE/
├── 07_PROTOCOLOS/
├── 08_FUENTES_Y_REFERENCIAS/
├── 09_PRODUCTOS_DE_CLASE/
├── 10_BITACORA_Y_DECISIONES/
└── 99_ARCHIVO/
```

## Principio
La estructura es deliberadamente compacta. No se replica todavía el Framework Genérico completo: se preserva control sin añadir ceremonia innecesaria.

## Ubicación de nuevos documentos
- Decisiones y estado → `00_CONTROL_MAESTRO`
- Fundamentos conceptuales → `01_FUNDAMENTOS`
- Rector → `02_DOCUMENTO_RECTOR`
- FEHE → `03_FEHE_H1-H10/Hx`
- Evaluación/alineación → `04_ALINEACION_Y_EVALUACION`
- Investigación PROEMA → `05_PROEMA`
- Plantillas y montaje → `06_OVAT_Y_MOODLE`
- Protocolos → `07_PROTOCOLOS`
- Fuentes → `08_FUENTES_Y_REFERENCIAS`
- Productos finales de clase → `09_PRODUCTOS_DE_CLASE`
- Bitácora/gates → `10_BITACORA_Y_DECISIONES`
- Obsoletos conservados → `99_ARCHIVO`
